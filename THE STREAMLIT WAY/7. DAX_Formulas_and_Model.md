# Hospital Emergency Admissions - Data Model & DAX Formulas

```
        | PK: Date_Key      |           | PK: Patient_Key  |

        | Year, Quarter     |           | First_Initial    |
        | Month_Number/Name |           | Last_Name        |
        | Day_Of_Week       |           | Gender           |
        | Day_Type          |           | Age, Age_Group   |
        +---------+---------+           | Race             |
                  |                     +--------+---------+
                  |                              |
                  | 1                            | 1
                  |                              |
                  | *                          * |
            +-----+------------------------------+-----+
            |                Fact_Admissions           |
            +------------------------------------------+
            | PK: Admission_ID                         |

            | FK: Department_Key                       |

            | Wait_Time_Minutes                        |

```

## 2. Complete DAX Formula Catalog

### Category A: Core Volume & Admission Metrics
```dax
-- Total Patient Volume
Total Patients = COUNTROWS('Fact_Admissions')

-- Total Admitted Patients
Total Admitted Patients = 
CALCULATE(
    COUNTROWS('Fact_Admissions'),
    'Fact_Admissions'[Admission_Flag] = 1
)

-- Total Non-Admitted Patients
Total Non-Admitted Patients = 
CALCULATE(
    COUNTROWS('Fact_Admissions'),
    'Fact_Admissions'[Admission_Flag] = 0
)

-- Admission Rate Percentage
Admission Rate % = 
DIVIDE(
    [Total Admitted Patients],
    [Total Patients],
    0
)
```

### Category B: Wait Time & Operational Efficiency
```dax
-- Average Wait Time in Minutes
Avg Wait Time (Mins) = AVERAGE('Fact_Admissions'[Wait_Time_Minutes])

-- Median Wait Time in Minutes
Median Wait Time (Mins) = MEDIAN('Fact_Admissions'[Wait_Time_Minutes])

-- Total Cumulative Wait Time (Hours)
Total Wait Time (Hours) = 
DIVIDE(
    SUM('Fact_Admissions'[Wait_Time_Minutes]),
    60,
    0
)

-- Patients Waiting > 45 Minutes (Threshold SLA)
Long Wait Patients (>45m) = 
CALCULATE(
    COUNTROWS('Fact_Admissions'),
    'Fact_Admissions'[Wait_Time_Minutes] > 45
)

-- % of Patients with Excessive Wait Time
% Long Wait Patients = 
DIVIDE(
    [Long Wait Patients (>45m)],
    [Total Patients],
    0
)
```

### Category C: Patient Satisfaction & Experience
```dax
-- Average Satisfaction Score (Rated only)
Avg Satisfaction Score = AVERAGE('Fact_Admissions'[Satisfaction_Score])

-- Total Patients who submitted a rating
Total Rated Patients = 
CALCULATE(
    COUNTROWS('Fact_Admissions'),
    NOT(ISBLANK('Fact_Admissions'[Satisfaction_Score]))
)

-- Survey Response Rate %
Feedback Response Rate % = 
DIVIDE(
    [Total Rated Patients],
    [Total Patients],
    0
)

-- High Satisfaction Patients (Score >= 8)
High Satisfaction Patients = 
CALCULATE(
    COUNTROWS('Fact_Admissions'),
    'Fact_Admissions'[Satisfaction_Score] >= 8
)

-- High Satisfaction Rate %
High Satisfaction % = 
DIVIDE(
    [High Satisfaction Patients],
    [Total Rated Patients],
    0
)

-- Low Satisfaction Patients (Score <= 4)
Low Satisfaction Patients = 
CALCULATE(
    COUNTROWS('Fact_Admissions'),
    'Fact_Admissions'[Satisfaction_Score] <= 4 &&
    NOT(ISBLANK('Fact_Admissions'[Satisfaction_Score]))
)

-- Low Satisfaction % (Alert / Risk metric)
Low Satisfaction % = 
DIVIDE(
    [Low Satisfaction Patients],
    [Total Rated Patients],
    0
)
```

### Category D: Time Intelligence & Trends
```dax
-- Patients Month-to-Date
Patients MTD = TOTALMTD([Total Patients], 'Dim_Date'[Full_Date])

-- Patients Year-to-Date
Patients YTD = TOTALYTD([Total Patients], 'Dim_Date'[Full_Date])

-- Patients Previous Month (MoM)
Patients PM = 
CALCULATE(
    [Total Patients],
    PREVIOUSMONTH('Dim_Date'[Full_Date])
)

-- Month-over-Month Growth %
MoM Patient Growth % = 
DIVIDE(
    [Total Patients] - [Patients PM],
    [Patients PM],
    0
)
```
